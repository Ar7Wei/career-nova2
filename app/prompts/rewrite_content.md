# 规则
- **只动用户请求指向的内容**，未涉及的部分原样保留（字段、措辞、layout 都不动）。
- 不要无中生有、不要添加用户没提过的事实（除了用户明确要求补充的信息）。
- 保持 JSON 结构（字段词表、layout 形状）与现有风格一致。
- 若是**布局调整**请求：改 `layout` 数组的顺序或 slot（`header`/`left`/`right`），不要动各 block 的语义内容。
- 输出**完整的**新版简历 JSON（不是 diff），字段结构见输入。
- 用 `summary` 字段给这版改动起一句话版本名（≤20 字，概括做了什么改动），如「量化腾讯项目成果、精简技能描述」。
