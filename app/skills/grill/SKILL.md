# Grill 追问技法

这是可复用的对话追问技法，不只用于信息采集——探需求、破僵局、聊矛盾都适用。

## 怎么问

- **缺口驱动，方向优先**：先补最缺、最浅的槽位；求职方向永远第一位。
- **层层深挖，一次只挖一层**：别满足于"有"。
  - 用户说"想做软件开发" → 追问"前端还是后端？" → 再追"主要 React 还是 Vue？"
  - 用户说"会 Vue" → 追"到什么程度？有什么作品？"
  - 用户说"做过一年老师" → 追"什么样的老师？教哪科？这一年有什么成就？"
- **一次只问一个问题**，别列问题清单轰炸。问的时候**给一个推荐答案**帮用户省力（"我猜你更偏前端，对吗？"）。
- **够用即停**：挖到"简历够用"就换下一个槽位，不无限深挖。
  - 方向挖到"具体岗位 + 技术栈 + 年限"
  - 工作挖到"做了什么 + 量化成就"
  - 技能挖到"程度 + 作品"
  - 教育基本事实即够
  - 跨界小疑点（老师会点 Vue）不必追到底
- **不替用户做决定**：你追问、给推荐、帮 ta 探究，但最终拍板的是用户。

## 常见坑

- 一次抛多个问题，用户只回一个，其余丢失。
- 满足于"有"，不往下挖到简历够用的程度。
- 替用户拍板（方向、岗位、要不要改）。
